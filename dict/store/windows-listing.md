## Description

Multiple dictionaries, one page.

Type a Pāḷi or Sanskrit word once and read every entry side by side: dictionaries, glossaries and canon definitions in a single answer. No tab juggling, no app switching.

WHAT IS INSIDE
Digital Pāḷi Dictionary, the PTS Dictionary, the Gandhari Dictionary, Sanskrit dictionaries (Monier-Williams, Shabda-Sagara and more), the Buddhadust Glossology, and definitions and similes from the Suttas and the Vinaya.

WORKS OFFLINE
The app opens with no network. Download the compact offline dictionary once, and short meanings keep working on a plane or in a retreat.

FOUR WAYS TO TYPE
Pāḷi with diacritics and autocomplete, Velthuis (kacchapaa gives kacchapā), English, or Russian. Type the word however you already have it.

GRAMMAR YOU CAN ACTUALLY READ
Declension and conjugation tables sort themselves: click a column header to order by case, number or gender.

STRAIGHT FROM THE CANON
Alongside the dictionaries you get definitions and similes as the suttas and the Vinaya give them, and a link that opens the word's matches in Dhamma.Gift.

YOUR DICTIONARY ON ANY SITE
The same lookup works as a browser extension: select a word on any page and read the answer there.

RECENT WORDS, FAVOURITES, FIND ON THE PAGE, LIGHT AND DARK THEME, FONT SIZE

Interface in English and Russian. Free, no ads, no accounts, no tracking.

Part of the Dhamma.Gift project: https://dhamma.gift

## Restricted capability runFullTrust (Submission options)

Needed for PWA Hosted App model, created by pwabuilder.com.

This app is a Progressive Web App (https://dict.dhamma.gift) packaged for the Microsoft Store with PWABuilder. The package contains no code of its own: it launches the Microsoft Edge (Chromium) PWA host, which runs as a full-trust process, and the host displays the web app in its own window. The runFullTrust capability is required only to start this host. The app does not use it for anything else: no access to user files, the registry or other apps.
