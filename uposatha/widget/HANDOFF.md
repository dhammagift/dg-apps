## Что решено (владелец, 10.10)
- Не «3 размера x 3 слоя», а семь отдельных виджетов, как в Daff Moon: Луна 1x1, Луна + упосатха 2x1, Упосатха 2x2, Упосатха 4x1, Упосатха 4x2, День и ночь (2x2),
  Календарь 4x4. Маленькие = один сценарий. Большие (4x2, 4x4) = три слайда (упосатха / день и ночь / календарь) с переключателем внизу; 4x2 открывается на
  упосатхе, 4x4 на календаре. «Если что, лишние уберём».
- Виджет при растягивании остаётся собой, только крупнее (дизайн масштабируется под ячейку); календарь не сжимается меньше 4x3.
- Одни и те же слова на всех размерах; без слова UPOSATHA; строка луны = луна СЕЙЧАС (8 названий фаз + %); ничего не обрезается многоточием.
- Режим «Подробно» / без него есть в виджете (по настройке приложения, можно переопределить в настройках виджета).
- Новолуние: пепельный свет вместо чёрного диска (одобрено: «супер»).
- У виджета свои настройки: тема (система / светлая / тёмная), прозрачность фона ползунком, подробно, строка kala, слайды, в календаре «луна каждого дня» и список «дальше».
- В настройках приложения новый переключатель «Луна каждого дня в календаре» (по умолчанию выкл); виджет-календарь следует ему.
- Фон карточки = оттенок карточки приложения, не белый.
