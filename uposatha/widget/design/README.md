# Uposatha — виджет со слоями и луна `<dg-moon>`. ТЗ

Пакет:
- `Uposatha Widget (макет).html` — все размеры, слои, состояния, светлая и тёмная тема, экран блокировки. Справа внизу — панель твиков («Подробно», kala, язык). Открывается без интернета.
- `Uposatha Moon (луна).html` — луна: ползунок фазы, полный цикл, 8 фаз, размеры, моно, юг.
- `dg-moon.js` — луна для сайта и приложения (WebView). Без зависимостей.
- `strings.json` — все тексты виджета, ru/en.
- Этот файл — ТЗ.

Источник истины по логике упосатх — приложение (`uposatha-core.js` / `uposatha-calendar.js`, dg-node@main). Виджет **ничего не считает сам**: режимы «по суттам / не по суттам», «Подробно», место, полдень — всё берётся из приложения.

---

## 1. Состав

Один виджет, три слоя. Порядок и набор слоёв задаются в настройках виджета (долгое нажатие → «Изменить»); выбранный слой запоминается для каждого экземпляра отдельно.

| # | Слой | Что показывает | Тап по площади ведёт в |
|---|---|---|---|
| 1 | Упосатха + kala | до какого дня, счётчик, подробности, kala/vikala | вкладка «Главная» |
| 2 | День и ночь | текущая стража, шкала суток, kala/vikala | вкладка «Части» |
| 3 | Месяц | сетка месяца с упосатхами, ближайшие | вкладка «Календарь» |

Размеры: малый 2×2 (170×170 pt), средний 4×2 (364×170), большой 4×4 (364×382), экран блокировки iOS (прямоугольный 158×72, круглый 72, строка). Все со слоями, кроме строки над часами.

## 2. Переключение слоёв

- Точки внизу — **кнопки**: нажатие листает слой и **не открывает** приложение. Свайпа нет — одинаково на iOS и Android.
- iOS 17+: `Button(intent:)` (App Intents), на iOS 16 — один слой без точек. Android: `setOnClickPendingIntent` на полосу точек.
- Точки визуально 16 pt в высоту, но область нажатия — вся нижняя треть виджета (≥ 44 pt).
- Неактивная точка 5×5, активная 14×5, цвет `--dg-accent-ink`, остальные `--dg-border-strong`.
- Прямоугольный на блокировке: точки вертикально справа. Круглый: точек нет, нажатие на весь круг листает (до начала → кольцо kala → дата). Строка над часами — без кнопок: один слой, выбирается в настройках.

## 3. Слой 1 — Упосатха + kala

Сверху вниз:
1. Подпись `УПОСАТХА · вс 11 окт` (капс, `--dg-accent-ink`; дата — `--dg-text-muted`).
2. «до 15-го дня» (8-го, 14-го) — до какого дня отсчёт.
3. Счётчик **дни + часы**, без минут: `1 д 7 ч`. Отсчёт идёт до **начала** — заката накануне. Когда упосатха идёт — «идёт 15-й день · до конца» и счётчик до рассвета следующего дня (`20 ч`).
4. Подробности — по настройке приложения **«Подробно»**:
   - вкл: «новолуние · 15-й день» + «сб 10, 18:08 → пн 12, 07:15»;
   - выкл: только «с сб 10, 18:08».
5. Строка kala — по настройке приложения «показывать kala» (как на главном экране; выкл там — выкл здесь):
   - kala: `Kala до 12:41 · ещё 1 ч 34 мин` (зелёный `--dg-accent-ink`);
   - vikala: `Vikala до рассвета 07:13` (бордовый `#9b1c31`, тёмная тема `#d8546b` — литерал прода `.mstat[data-k=vikala]`);
   - **без полосы прогресса**: вне kala ей нечего показывать.
   - Если kala выключена, строки нет, а луна и счётчик крупнее.
6. Место не указано: время условное (18:00 и 06:00), полдень 12:00 «по часам» — как `#noonseg[data-fixed]` в приложении. Тап ведёт в настройку места.

Большой 4×4 дополнительно: подпись режима («по суттам» / «не по суттам») и список «Дальше» — три следующие упосатхи (луна, дата, «8-й день», «через 8 д»).

## 4. Слой 2 — День и ночь

- Название текущей стражи + «середина дня · до 14:30».
- Справа — kala/vikala. **Здесь всегда**, независимо от настройки главного слоя: это часть суток.
- Шкала суток от рассвета до рассвета: три стражи дня (`--dg-accent` 28 %), три ночи (`--dg-navy-ink` 30 %), текущая — сплошной `--dg-accent`, метка «сейчас» — 2 px `--dg-text`.
- Подписи: рассвет, полдень, закат.
- Большой: список шести стражей с границами; текущая — плашка `--dg-navy-ink` 22 %.
- Названия и границы стражей берутся из вкладки «Части» приложения (в макете они условные).

## 5. Слой 3 — Месяц

- Сетка как в приложении (`.grid .c`): начало упосатхи (вечер накануне) — сплошной `--dg-accent`, белый текст; сам день — `--dg-accent` 30 % поверх поверхности, текст `--dg-accent-ink`; вечер и день сливаются в одну полосу. Сегодня — обводка 1.5 px `--dg-text`. Прошедшие дни — `--dg-text-muted`.
- Средний: слева ближайшие три (луна, дата, день), справа сетка. Большой: сетка крупно + ближайшая.
- **Числа нажимаются** в 4×2 и 4×4: каждое число — своя ссылка (iOS `Link(destination:)`, Android `setOnClickPendingIntent` на ячейку). Число открывает «Календарь» на этом дне, а день упосатхи — сразу подробности. В 2×2 на iOS вся площадь — одна цель.

## 6. Типографика (шкала)

Шрифт Lato (как у прода). Минимум текста на виджете — **11.5 px**; единственное исключение — дни недели над сеткой месяца (10.5 px).

| | подписи | текст | «до N-го дня» | счётчик | луна |
|---|---|---|---|---|---|
| Малый 2×2 | 11.5 | 12.5 | 12 | 34 (kala выкл — 40) | 22 |
| Средний 4×2 | 11.5 | 13 | 13 | 38 (44) | 66 (76) |
| Большой 4×4 | 12.5 | 15 | 15 | 54 (58) | 90 (100) |

Единицы счётчика (`д`, `ч`) — 16 px, weight 500. Луна в среднем и большом по высоте ≈ «до N-го дня» + счётчик + первая строка.

## 7. Данные — контракт с приложением

Приложение пишет в общее хранилище (iOS: App Group `UserDefaults`, Android: `SharedPreferences`) при каждом открытии и раз в сутки — готовые записи на **14 дней**:

```json
{
  "generatedAt": "2026-10-09T11:07:00+03:00",
  "settings": { "lang": "ru", "bySuttas": true, "detail": true, "showKala": true, "placeSet": true, "south": false },
  "uposathas": [
    { "start": "2026-10-10T18:08", "day": "2026-10-11", "end": "2026-10-12T07:15",
      "lunarDay": 15, "phaseName": "new", "phase": 0.0 }
  ],
  "days": [
    { "date": "2026-10-09", "sunrise": "07:12", "noon": "12:41", "sunset": "18:10",
      "parts": [ ["pubbanha","07:12","10:51"], ["majjhanhika","10:51","14:30"], ["sayanha","14:30","18:10"],
                 ["pathama","18:10","22:31"], ["majjhima","22:31","02:51"], ["pacchima","02:51","07:13"] ] }
  ]
}
```

Виджет только раскладывает эти данные. Ни сети, ни геолокации, ни своих лунных расчётов.

## 8. Обновления и производительность

- Таймлайн на сутки: запись **каждый час** (для счётчика `1 д 7 ч`) + точные — рассвет, границы стражей, полдень (kala → vikala), закат (начало упосатхи). Около 30 записей готовятся одним заходом — это **одно** обновление из бюджета iOS (≈ 40–70 в день).
- «ещё 1 ч 34 мин» — системный таймер текста (`Text(timerInterval:)` / `Chronometer`), без перерисовок.
- Android: тот же почасовой план через `AlarmManager`; чаще раза в 30 мин система сама не будит.
- Сменили настройку в приложении → `WidgetCenter.reloadAllTimelines()` / `AppWidgetManager.updateAppWidget()`.
- Батарея: практически ноль — расчётов в виджете нет.

## 9. Луна `<dg-moon>`

Одна луна для сайта, приложения и виджета вместо эмодзи (`MOON_N` / `MOON_S` в `uposatha-calendar.js`).

- **Фаза непрерывная**: 0 — новолуние, 0.25 — первая четверть, 0.5 — полнолуние, 0.75 — последняя. Терминатор — эллипс с полуосью `R·|cos 2πf|`.
- **Тень поверх целой луны**: в новолуние видна та же луна в тени — пепельный свет, фактура едва читается. Тень двойная: резкая (blur 1.3) + широкая полутень (blur 4.5, 50 %). Цвет тени — `--dg-navy` 70 % + чёрный.
- **Фактура** процедурная, генерируется один раз на страницу (~50 мс): моря на своих местах видимой стороны, рельеф шумом, ~500 кратеров со степенным законом размеров и ракурсом к краю, лучевые Тихо / Коперник / Кеплер. Серо-тёплая палитра — это изображение, а не цвет интерфейса.
- Затемнение к краю, тонкий ободок `--dg-navy-ink` 22 % — держит полнолуние на белом.
- Атрибуты: `phase`, `south` (поворот на 180°), `mono` (экран блокировки), `glow` (свечение по освещённости, для тёмных фонов).
- Размер — `1em`: задаётся `font-size`.

Подключение (сайт и приложение):
```html
<script src="/assets/js/dg-moon.js"></script>
<dg-moon phase="0.5"></dg-moon>
<script>
  el.phase = m.f;                                   // m.f — уже считается для moonSvg в нижней панели
  el.animateTo(m.f, { cycles: 1, duration: 2000 }); // плавный круг
  if (state.south) el.setAttribute('south', '');
</script>
```

Виджет (нативный, JS там нет):
- Фактуру выгрузить один раз — `DgMoon.texture()` возвращает data-URL; сохранить PNG 420×420 в ресурсы (Assets.xcassets / `res/drawable-nodpi`).
- Тень рисовать той же геометрией: `DgMoon.shadePath(f)` / `DgMoon.litPath(f)` (SVG-path в системе 100×100, центр 50, R 48). SwiftUI — `Path` + `.blur`, Android — `Canvas` → bitmap.
- Экран блокировки iOS: моно-вариант или SF Symbol `moon.phase.*`.

## 10. Анимация

- **Цикл луны** (тап по луне): один полный круг фаз и остановка на текущей. 2000 мс, easing in-out cubic, непрерывно по фазе (не кадрами). `prefers-reduced-motion` — без анимации, сразу текущая.
- В самом виджете покадровой анимации нет ни на iOS, ни на Android. iOS 17+ даёт один переход по тапу (`contentTransition`); Android `ViewFlipper` не умеет остановиться после круга. Поэтому **полный цикл играет в приложении** — тап по луне в виджете открывает «Главную», и цикл идёт там при появлении.
- Нажатие на луну в макете: `scale(.94)` 120 мс.
- Смена слоя по точкам: системный переход виджета, своих анимаций нет.
- Тайминги экранов приложения — `guidelines/redesign/animations.md`.

## 11. Тема и цвета

Только токены `--dg-*` (`styles.css` / `tokens/`). Исключение — бордовый vikala (`#9b1c31` / `#d8546b`): это литерал прода, токена для него нет. Тема — системная; на iOS 18 в тонированном режиме всё одним цветом, и kala/vikala различаются словом.

## 12. Тексты

Все строки ru/en — `strings.json`. Язык — язык приложения.

## 13. Открытые вопросы

- Названия и границы стражей сверить с вкладкой «Части» приложения.
- Фактура луны — процедурная. Если нужен фотореализм, на её место можно подставить общественное фото NASA; тень и анимация не меняются.
